# Semantic Portfolio Website

A multi-page personal portfolio website built using HTML5 semantic elements and accessibility best practices.

## Features

* Semantic HTML5 Structure
* Accessible Navigation
* ARIA Labels & Roles
* SEO-Friendly Meta Tags
* Accessible Contact Form
* Responsive Design

## Pages

* Home
* About
* Projects
* Contact

* CSS3
